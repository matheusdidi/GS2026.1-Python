## Objetivo

Desenvolver um sistema em Python capaz de monitorar dados simulados de uma missão espacial experimental.

## Funcionalidades

* Monitoramento de temperatura
* Monitoramento de comunicação
* Monitoramento de bateria
* Monitoramento de oxigênio
* Monitoramento de estabilidade
* Cálculo de risco por ciclo
* Classificação da missão
* Identificação da área mais afetada
* Relatório final automático

## Tecnologias

* Python 3

## Como executar

1. Abrir o terminal.
